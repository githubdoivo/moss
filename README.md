# moss.ivolopes.com

[![CI](https://github.com/githubdoivo/moss/actions/workflows/ci.yml/badge.svg)](https://github.com/githubdoivo/moss/actions/workflows/ci.yml)

**MOSS**: DJ and producer. For now, a "soon" page: a swamp at night, drawn
live on a canvas (`swamp.js`) with two soft treelines, drifting mist, reeds
swaying at the water's edge, and fireflies that wander, pulse, drift towards
the pointer and reflect in the water. No libraries. With "reduce motion" on,
it is a single still frame and all the text shows at once.

`npm test` runs the Playwright tests; `npm run og` re-renders the link preview.
